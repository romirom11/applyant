# Design documents

How Applyant was designed, in reading order:

- `task.md`: the original brief (Ukrainian)
- `02-research-job-harness-foundations.md`: research the design rests on (the TDD cites its sections)
- `03-prd-job-search-harness.md`: what the product does and for whom
- `04-tdd-applyant-harness.md`: how it's built: process layout, storage, queue, agents, forms, the Mac app
- `05-structure-outline-applyant-harness.md`: **the plan**, phase by phase, with progress notes for the phases done
- `mockup-*.html`: the Mac app's Inbox, Pipeline and Review screens (phase 8b)

The plan is the living one: whoever finishes a phase ticks its checkboxes and adds progress notes
there (what was built differently, what was checked by hand), in the same commit as the work.
